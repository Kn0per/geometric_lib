
# Math formulas
## Area

- Rectangle: S = ab
- Square: S = a²
- triangle S = a*h/2
## Perimeter

- Rectangle: P = 2a + 2b
- Square: P = 4a
- triangle P = a+b+c
# создание функций, которые выдают площади и периметры фигур
# описание функций: 
  triangle: 
    area(a, h) -Вычисляет площадь треугольника. Пример: area(5,4) - 10
    perimeter(a, b, c) -Вычисляет периметр треугольника.Пример: perimeter(1, 5, 4) -     10
  square:
    area(a) -Вычисляет площадь квадрата. Пример: area(5) - 20
    perimeter(a) -Вычисляет периметр квадрата.Пример: perimeter(1) - 4
  rectangle:
    area(a,b) -Вычисляет площадь прямоугольника. Пример: area(5,4) - 18
    perimeter(a,b) -Вычисляет периметр прямоугольника .Пример: perimeter(1,1)-
    4
